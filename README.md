# Krinik EPUB Linter

Проверка и починка русских EPUB-книг, сконвертированных из FB2 (типичные `*.fb2.epub`):

- **сноски** приводятся к одному виду `[N]` — обычным текстом, крупно, кликабельно в обе стороны;
- **корректура** — отчёт о возможных ошибках орфографии, грамматики и пунктуации, без правки текста.

Оригиналы никогда не изменяются: результат сохраняется в отдельную папку.

## Установка

Нужен Python 3.8+. Для починки сносок зависимостей нет.

```bash
git clone https://github.com/MikalaiKryvusha/Krinik-EPUB-Linter.git
cd Krinik-EPUB-Linter
python3 -m venv .venv
.venv/bin/pip install -e ".[proofread,dev]"   # proofread — LanguageTool, dev — pytest и ruff
```

Для корректуры через LanguageTool нужна Java 17+. При первом запуске LanguageTool скачивается (~260 МБ)
и дальше работает локально — текст книги никуда не отправляется.

## Команды

```bash
krinik-epub-linter survey  КНИГА.epub ...             # что за сноски в книге и какие с ними проблемы
krinik-epub-linter fix     КНИГА.epub ... -o ПАПКА    # причесать сноски
krinik-epub-linter check   ПАПКА/*.epub               # проверить результат (код возврата 1 при проблемах)
krinik-epub-linter proofread ПАПКА/*.epub -o ОТЧЁТЫ  # корректура: отчёты .md и .json
```

Вместо `krinik-epub-linter` можно запускать `python3 krinik_epub_linter.py`.

### fix — сноски

```bash
krinik-epub-linter fix "Tegmark.fb2.epub" -o Причёсанные \
    --author "Макс Тегмарк" --title "Наша математическая вселенная. В поисках фундаментальной природы реальности"
```

Файл сохраняется как `Имя Фамилия. Название.epub`; `--author` и `--title` также записываются в метаданные
книги. Без них берутся из метаданных как есть.

| Было | Стало |
|---|---|
| `инфляцией.¹⁶ Экстраполяция` (мелкая надстрочная) | `инфляцией. [16] Экстраполяция` |
| `ускорителя[28] в окрестностях` | `ускорителя [28] в окрестностях` |
| `Царств[20], – заметил` | `Царств [20], – заметил` — знак препинания остаётся сразу после ссылки |
| `к горе»[177].Сказано` | `к горе» [177]. Сказано` |
| `в мире ⇥⇥[64] ⇥⇥, чтобы` | `в мире [64], чтобы` |
| `строчка.<sup>{1}</sup>` | `строчка. [К1]` |
| Примечание: номер `88` отдельным заголовком, ниже текст | `[88] Текст примечания` — `[88]` ведёт обратно к месту в тексте |

Подробности:

- перед ссылкой — неразрывный пробел, чтобы `[N]` не переносилась на новую строку отдельно от слова;
- ссылки получают класс `krinik-fn` и явный стиль `font-size:1em; vertical-align:baseline` — это перебивает
  типичное для конвертеров `.a { font-size: 0.7em; vertical-align: super }`;
- обёртки `<sup>`/`<small>` вокруг ссылки снимаются;
- **две серии примечаний с одинаковыми номерами** (например, «Примечания» и «Комментарии») — меньшая получает
  приставку по первой букве заголовка: `[К1]`, `[К2]`. Вручную: `--prefix OPS/ch2.xhtml=К`;
- **ссылка ведёт не на то примечание** (номер `[52]`, а ведёт на 51) — если примечание с нужным номером
  существует и на него никто не ссылается, ссылка перенаправляется, это пишется в отчёт;
- не трогается: разделители `* * *`, формулы, степени (`10<sup>26</sup>`), обычные ссылки и перекрёстные
  ссылки на абзацы, нумерованные подзаголовки глав.

### proofread — корректура

Только отчёт: книга не меняется, решение по каждому месту — за человеком.

Встроенные проверки (без зависимостей), типичные следы распознавания и конвертации:

| Проверка | Пример |
|---|---|
| Смешение алфавитов | `Cтивен` (латинская C), `Ha этом` (латинские H и a) |
| Повтор слова | `пошли в в магазин` |
| Пробел перед знаком | `магазин , и` |
| Нет пробела после знака | `хлеб.Потом`, `сказано,сделано` |
| Дефис вместо тире | `Москва - столица` |
| Непарные скобки и кавычки | `(и замолчал.` |

LanguageTool добавляет орфографию, грамматику (согласование рода и падежа), пунктуацию и типографику.
Чтобы не ломать замысел автора, отключены категории, которые оценивают стиль, а не ошибки
(«перегружено местоимениями», «избыточные определения», «плеоназм»). Незнакомые LanguageTool слова
с заглавной буквы и часто повторяющиеся слова (имена, термины) вынесены в отдельный свёрнутый список.

## Тесты

```bash
.venv/bin/pytest
.venv/bin/ruff check .
```

Тесты собирают маленькие синтетические книги со всеми встречавшимися на практике случаями;
настоящие книги в репозиторий не входят.
